# 国考课的大纲骨架

九门课都已在课程目录里，大纲写在各自的课程文件里；课程不存在时，`guokao.mjs new` 按 `<题库>/outlines.data.js` 的默认大纲建课。**以课程文件里的大纲为准**；本文给出骨架规则、各科默认大纲一览和对话里的展示格式，供开题和调整大纲时参考。`<题库>`、`<国考题库>` 的含义见 TEMPLATE.md「题库在哪」。

## 1. 通用三段骨架（所有模块）

1. **第 1 课固定：考情与题型地图**（课程 id `kaoqing`）。本模块考几题、题号段、参考时限、分几类、每类近三年各考几题、2027 侧重推断（每条标「推断」并写依据）。有真题库（`<题库>/zhenti/<slug>.md`）的模块用数据；没有的只讲题号段和分类，分布一栏写「待拆解」，**不编数字**。本课不发题。两张表格卡「题型地图」「真题覆盖」放在这一课末尾，由脚本生成。
2. **中间每类题型一课**，按近三年（2024–2026）真题频率排序；三年合计 ≤ 2 题的类型标「可选」。一课只讲一类；一类讲不完就拆成两课（题型节点的 `lesson` 写成数组）。横跨各题型的方法可以单独成一门**方法课**（没有题型节点，不参与排序，如数量关系的 `beishu`、`fuhe`）。没有题量数据的模块按大纲知识主线排序，偏冷、偏细的标「可选」；计算机、证券期货按 2027 证监会大纲条目开课，大纲明列的条目都是主线，不为凑「可选」另设课。
3. **最后一课固定：策略课**（课程 id `celve`）。
   - 行测：「做与跳：限时策略」——时间预算、先做哪类、跳题线索、涂卡规则；课末一组与真题题量相同的限时练习。
   - 申论：「考场作答策略」——各题时间与字数分配、读材料与写作顺序、保底写法。
   - 计算机、证券期货：「串讲与多选辨析策略」——串成一条主线，归纳多选逐项辨析规则。

## 2. 怎么判断重点

- 有真题库：近三年题数多、每年都出现的类型是重点，放在主线前面；在大纲后写出依据（「方程与比例近三年 8 题，居首」）。
- 没有真题库：按官方大纲的主线和前置关系排序（先概念、后应用），不说「高频」，不编题量。
- 推断一律写成「推断：…… 依据：……」，样本小时说明只能看趋势。
- 一课只解决一类题；学习者要求合并或拆分时照做，题型节点的 `lesson` 按 TEMPLATE.md「调整大纲」改，再跑一次 sync。

## 4. 大纲在对话里的格式

```text
模块：行测 · 数量关系（副省级第 66–80 题，15 题，参考 10 分钟）
slug：xingce-shuliang（课程页：<课程目录>/xingce-shuliang/course.html）

1. 考情与题型地图 —— 15 题分十二类，近三年分布和 2027 推断，不做题
2. 倍数特性与代入排除 —— 整除、份数、奇偶、尾数、代入排除，横跨各题型的省时工具（方法课）
3. 方程与比例 —— 找等量关系，A 和非 A、排比句、鸡兔同笼（近三年 8 题）
4. 排列组合与概率 —— 分类分步、捆绑插空、平均分组、古典概率（7 题）
5. 几何 —— 面积体积、相似比、勾股，含带图题（6 题）
```
