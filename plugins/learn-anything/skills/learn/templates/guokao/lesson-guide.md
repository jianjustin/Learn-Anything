# 国考课讲课细则

本文是通用 lesson-guide.md 之上的国考课补充。插话、续学、补测、调整大纲的基本做法照通用细则；真题用途、三个脚本、练习记录的约定和掌握规则见 TEMPLATE.md。

## 1. 一段讲多少

- 一段只讲一个点：一个概念、一条识别线索、一个解法步骤、一道题的一段推理。
- **约 300 字以内**，最多一张简图或一张小表。
- 结构：先一句结论 → 两三句展开（为什么、怎么用）→ 一句「看到 xx 就想到 xx」（可选，要带适用条件）。
- 段末自然停下，措辞轮换，例如：
  - 「这里有疑问吗？没有的话我接着讲识别线索。」
  - 「你先想想：这句话里哪个量是总数？想好了再往下。」
  - 「先停一下——到这里能跟上吗？」
  - 「下一段是真题示范，要继续吗？」
- 学习者说「直接讲完这课」时连续讲完剩余各段（每段一个小标题），但变式题仍然发题即停。
- 每讲完一段更新 `resume.note`（一句话，约 60 字以内：讲到哪、下一步讲什么）和 `updatedAt`。

示例（一段，识别线索）：

```text
**怎么认出「方程与比例」**

结论：题里有两种以上的对象，各自带着单价、规格或基数，条件是它们之间的关系——这就是列方程的信号。

具体看三处：
- 关系词：「是……的 N 倍」「比……多」「提升为」「正好是……的 60%」；
- 问法：「共多少」「多多少」，答案是整数个数或金额；
- 选项：都是整数且间隔大，可以回代核对，甚至直接代入排除。

反过来，未知量超过三个、条件互相缠绕的，先别急着列式，标记后放到最后。

到这里能跟上吗？下一段讲解法：设谁、怎么用整除先筛选项。
```

## 2. 每课七步细则（题型课和方法课）

1. **开课先改页面**：本课 `current`、更新 `resume`，校验。对话里一两句话说本课讲哪类题、在题型地图上的位置、和上一课的关系。
2. **是什么、考什么**：这类题考什么能力（翻译关系、读图、辨析概念……）；近三年哪几题属于它，按「2024 年第 62、63、67 题；2025 年第 66、67 题；2026 年第 66、69、76 题」列出——**2025、2026 只有题号**；本库的归类口径（容易归错的边界）一并说明。本课有哪些题：「题型地图」里对应本课的题型，在题库 md 里归到这些题型的条目；申论、计算机、证券期货看题库 md 开头的「按课汇总」。
3. **识别线索**：正向线索（关键词、结构、问法、选项特征）和反向线索（表面相似但不是、或者应该先跳的）。
4. **解法与适用条件**：步骤；常用技巧（赋值、代入排除、整除特性、列表枚举、比例……）；**不适用的情形**；一个自检办法（回代、量纲、估算）。
5. **真题示范**：从题库的 `demo` 题里选一道最典型的，排除 `- 一致：存疑`、`- 一致：待核` 的题。先给出处和题干，再按六步讲：
   - **题目信息**：读出已知量、所求量、单位；
   - **识别**：命中了哪条识别线索；
   - **列式**：设什么、列什么；
   - **求解**；
   - **核对选项**：回代验证，指出哪个干扰项是给半路停手的人准备的；
   - **用时判断**：这题考场上该做还是该跳、预计用时。

   可以先请学习者看题想 30 秒再展开，但不要求作答。讲完按 TEMPLATE.md「示范和题图怎么落到页面」写 `steps` 卡、放题图、跑 `sync --demo`。复合题课可以示范 2–3 道不同组合，每道一张 `steps` 卡，写完一张就先处理它的题图，再写下一张。
6. **变式练习**：见第 3 节。
7. **课末**：3–5 条小结 → 按 TEMPLATE.md「课末的卡片」写卡 → 本课 `done`、下一课 `current`、更新 `resume`，校验 → 问是否进入下一课。

## 3. 变式练习

### 出题

- 原创变式，题目以「原创变式 N：」开头，`q` 末尾另起一行写出题依据「出题依据：仿 2024-63（……）」，括号里写改了什么。不以 `hold`、`drill`、存疑、待核题为蓝本。
- **换条件或情境，不只换数字**：换掉倍数作用的对象（「总数是 2 倍」→「个数是 2 倍」）、加一条干扰信息、反过来问、换成另一个生活情境。目标是检验识别和建模，而不是重复同一套计算。
- **第 2 道变式优先递进为复合题**：第 1 道答对后，第 2 道出「本课模型为主 + 一个辅工具」的题（如方程 + 整除、最值 + 工程效率、行程 + 勾股），检验能否在条件里认出第二个模型；第 1 道答错时第 2 道不加辅工具，先把本课模型练稳。各模块都适用；数量关系的辅工具选择、蓝本和拆解顺序以 `<题库>/shuliang-models.md` 第 14 节为准。
- 出题前自己**独立解一遍**，逐个选项确认只有一个成立；数字设计成能心算或简单笔算。
- 一次发一道。发题的同时往本课 `practice` 卡追加一条，只写 `q`（选择题不写 `rubric`），**不写 `answer`**（页面一有 `answer` 就显示），运行校验；`resume.note` 写「变式 N 已发出，待作答」。
- **发题即停**：「先自己做，做完把答案（最好连同关键一步）发给我。」不附提示、不附答案。

一条发出时的样子：

```json
{ "q": "原创变式 1：……\nA.600　B.700　C.800　D.900\n出题依据：仿 2024-63（换了倍数作用的对象）" }
```

### 批改

1. 先判对错，给出正确选项。
2. 答错时定位**错在哪一步**（读题、设未知数、列式、计算、核对），把它链接回第 2–4 步的具体一点：「这正是识别线索里说的『个数还是总数』」。
3. 补全这一条：`yours` 写学习者的原话（报告了用时就另起一行接「（用时 N 分钟）」），`ok`，`answer` 写正确选项和关键一步；答错时 `why` 以「错因：<中文>。」开头，只记一个有作答证据的主因，其他次要原因写在后面。错因七选一：

| 错因 | 含义 | 回链到 |
|---|---|---|
| 概念不清 | 不知道这个模型或公式 | 第 2 步「是什么」或第 4 步解法 |
| 审题 | 看错量、看错问法 | 第 3 步识别线索 |
| 方法 | 方法选错或用错（该代入却硬解、赋值对象错） | 第 4 步解法与适用条件 |
| 计算 | 计算错 | 第 4 步的自检办法 |
| 条件用错 | 漏条件或误用条件（「提升为」当「提升了」） | 第 3 步反向线索 |
| 时间 | 会做但超时 | 示范里的用时判断 |
| 不明 | 无法定位 | 追问一句，定位后改写 `why` |

4. 学习者只给了选项字母、看不出错在哪：先记「错因：不明。」，追问**一句**区别性问题（「你设的未知数是什么？」），不凭一个干扰项猜他的思路；问清后改写这条 `why`。
5. 按通用规则处理掌握：答对，并且 `review` 里没有指向本课的条目，本课 `mastered: true`；答错，往 `review` 末尾加一条（`text` 写成下次能直接拿来问的样子，如「说出『个数是 2 倍』和『总数是 2 倍』列式的区别」），本课 `mastered: false`。运行校验。
6. 答对：肯定关键一步，可以问一句「有没有更快的办法」。
7. **出几道**：第一道答对 → 再出一道换角度（换条件或问法）的变式；答错 → 讲清错因后最多再给一道；每课最多 2 道。不连发同类题；第二道仍然错，建议课后回看对应卡片。第二道批改完（或第一道答错后学习者不想再做）进入课末。

答错后的样子：

```json
{ "q": "原创变式 2：……\n出题依据：仿 2024-63（倍数改成个数）", "yours": "A\n（用时 3 分钟）", "ok": false, "answer": "D。设小号 x 个，大号 2x 个……", "why": "错因：审题。把「个数是 2 倍」读成「总展板数是 2 倍」，回到识别线索第 1 条" }
```

## 4. 各科练习形式

- **行测**：单选，四个选项；变式题干要短，贴近真题长度。资料分析题要给完整的材料（表格、单位、时间范围），不能用「[图略]」。
- **申论**：变式改为**小题作答**——给一段材料（标段落号）和作答要求（任务动词、对象、范围、字数），学习者写要点。
  - 发题时 `q` 写材料和作答要求全文；`rubric` 写成要点清单，每条一个能判断有没有写到的意思，并写明门槛（如「6 条要点覆盖至少 4 条，且没有材料之外的内容」）。
  - 反馈逐点对材料：建「应有要点 → 材料段落 → 学习者原句 → 覆盖程度（完整 / 部分 / 缺失）」表，指出最关键的 1–3 处修改并给替代表达。
  - **你自己判 `ok`**：对照给定资料和 `rubric` 的门槛判，不交给 `answer-grader`。`yours` 存学习者原文，`answer` 存参考要点并标「AI 参考，非官方答案」，没过门槛时 `why` 写缺了哪几条要点。不打分，学习者要求估分时才给范围和依据。
- **计算机、证券期货**：以单选、多选为主，当场判。多选**逐项**给对错理由，漏选不按全对处理。计算题写明单位、假设和初始状态；SQL 题给出数据集；制度题写明依据的规则和施行时间。

## 5. 考情课（第 1 课）

讲本模块考几题、题号段、参考时限、分几类、每类近三年各考几题（有真题库用数据，没有写「待拆解」，不编数字），以及 2027 侧重推断（每条写成「推断：…… 依据：……」，不说「高频」，样本小时说明只能看趋势）。提到 2025、2026 的题只说题号和题型。分段照第 1 节。

页面上的「题型地图」「真题覆盖」两张表格卡已经在本课里，讲分布时提醒学习者看。本课不发题；课末按 TEMPLATE.md 写卡，设 `done` 时同时设 `mastered: true`。

## 6. 策略课（最后一课）

### 行测「做与跳：限时策略」

分三段讲，再做组练：

1. **时间预算**：本模块在整卷中占多少时间（数量关系参考 10 分钟 / 15 题），和其他模块怎么换时间。
2. **顺序与跳题线索**：回到「题型地图」表，把每类题标成「先做」「看情况」「先跳」；列出跳题线索（未知量多、条件缠绕、要分很多类讨论、算到一半数字不整、读完题 30 秒还没思路）。
3. **涂卡与猜题**：跳过的题怎么标记、最后两分钟怎么处理、猜题时如何用选项特征排除。

### 限时组练

题量与真题相同。数量关系用 2022 副省级第 61–75 题（`drill`），存疑、待核题除外，参考 10 分钟。

1. **先定门槛**：请学习者自己定过关门槛（正确率和用时，如「15 题对 11 题、10 分钟内」）。
2. **发题**：本课建一张 `practice` 卡，标题如「限时组练 · 2022 副省级 61–75 题」。第一条是汇总：`q` 写「15 题限时组练，参考 10 分钟」，`rubric` 写学习者定的门槛。其后每题一条：`q` 写题号和题型（如「2022-61 方程与比例」），不必抄题干。运行校验。然后一次发完整组（题干从真题库条目读），说明「自己计时，做完一次性报用时和每题答案，跳过的写『跳』」，停下等。
3. **学习者报告后**：给出对错，统计作答数、对题数、用时，逐个看跳过的题跳得对不对、做错的题错因是什么。**只记用时、作答数、对错和跳题依据**，不打分、不算掌握率。
   - 每题条目：作答的写 `yours`、`ok`、`answer`，答错的 `why` 写「错因：……」；跳过的记 `skipped: true`，`why` 写「跳题依据：……」。各题条目不单独改 `mastered`。
   - 汇总条目：`yours` 写作答数、对题数、跳了哪几题，另起一行「（用时 N 分钟）」；`answer` 写本组的参考结果（对题数和各题答案）；按门槛判 `ok`，没过关时 `why` 写差在哪。本课 `mastered` 跟着汇总条目走。
   - 有错题或没过关：往 `review` 末尾加**一条**，`lesson` 写本课 id，`text` 列出错题题号和错因（超时就写超了多少），如「组练错题：2022-64（审题）、2022-71（方法）；超时 2 分钟」。
   - 运行校验。
4. 没有 `drill` 真题的模块：先建议学习者按 `import-questions.md` 导入一年真题作组练；不导入才用原创题组，卡片标题标「原创组练」，各题 `q` 写全题干。

### 申论「考场作答策略」

各题的时间与字数分配、先读材料还是先看题、提纲怎么打、卡住时的保底写法（先保要点覆盖、再求语言）。课末一道限时小题：可以选一整套卷中的一题，按第 4 节申论的写法发题和判 `ok`，`yours` 末尾另起一行记用时和字数。

### 计算机、证券期货「串讲与多选辨析策略」

把本模块串成一条主线（一张表或一段话）；归纳多选辨析规则（绝对化表述、主体错位、条件缺失、新旧规则混用）和本模块的易混对。课末一组限时单选、多选（可以直接用一整年的题），记法同上面的限时组练：先定门槛，汇总条目判 `ok`，各题逐项记对错，只加一条待回顾。

## 7. 插话处理

- 照通用细则：先回答，偏离本课的说放到第几课或记进待回顾（`lesson: null`），课末写进 `questions` 卡。
- 学习者问到 2025、2026 的具体题目：说明这两年留作整卷（11-14、11-21），只告诉题号和题型；学习者明确说已经做完那套整卷、要复盘，才可以讲。

## 8. 续学回顾

读完课程文件后，用两三句话回顾，然后跑一次 sync，再从断点继续：

```text
我们在「数量关系」学到了第 3 课「排列组合与概率」（已讲 2 / 16 课，已掌握 2 课）。
上次讲到：识别线索讲完了，下一步讲分类分步和捆绑插空。
上一课的变式 2 你错在审题（个数还是总数），这一课也会遇到类似的陷阱。
课程页：/……/xingce-shuliang/course.html
```

- 已讲、总课数和已掌握用列课程命令输出的 `done`、`total`、`mastered`。
- 本课 `practice` 里有既没有 `yours` 也没有 `skipped` 的条目：先原样重发那道题并等作答，再做别的。组练条目只有题号时，从真题库按题号读出题干再发。
- 上一课 `practice` 里有答错的题，回顾时提一句错因，帮助衔接。

## 9. 各科注意

**行测**

- **资料分析**：分清增长量、增长率和百分点。8% − 5% = 3% 作为算式成立，但描述增速变化应说「提高 3 个百分点」，相对原增速则是上升 60%（3 ÷ 5），不能按运算符号机械决定单位。基期量与现期量：增长率的分母是基期量，「现期 ÷ (1 + r)」求基期，别把现期当分母。保留材料的单位、时间范围和图例。
- **判断推理**：加强削弱先列论点、论据和隐含连接，再找替代原因、样本偏差、反例；「有关」不等于「支持」；不同论证类型不能共用一套无条件的强弱顺序。翻译推理分清充分条件与必要条件（「只有……才……」与「如果……就……」的方向相反）。定义判断逐条核要件。
- **数量关系**：写清分类是否互斥、分步是否独立。估算要看选项间隔，间隔小就不能粗估。算不完时记录跳题依据和用时。
- **言语理解**：先定位话题、转折与因果、作者态度，再比较选项的范围、强弱和是否偷换概念。逻辑填空分别核语义、搭配和语境，不要只给「转折看后面」。
- **政治理论、常识判断**：政策、会议、讲话的时间点和发布主体查官方原文（中国政府网、新华社、主管部门发布）；原文日期和题目适用年度分开；历史口径与现行口径分开写。法律题标法条版本与施行时间。核不到就说待核，不凭记忆给现行规定。

**申论**

- 不用外部常识填补材料：答案里的每个要点都要能回到材料段落。
- 概括问题 ≠ 提出对策：概括题不写「应当……」；对策要回应问题，有主体和动作。
- 综合分析说明词句在材料中的含义和关系；应用文服从文种、身份、受众要求；文章先有论点和论证，再补表达。

**计算机**

- 用原理、量纲和边界条件验证：主频 / CPI / 执行时间的换算写单位；复杂度分清平均与最坏；排序说明稳定性；事务隔离级别对应哪种异常。
- 具体数据库、操作系统的产品特性注明版本，不混用不同实现。
- 网络安全法规核施行日期；法规题按出题当年口径判对错。

**证券期货**

- 制度表述核现行官方文本（证监会、交易所、中国结算、各行业协会），写明适用市场和施行时间；问历史制度时标明当时有效文本并列出现行差异。
- 股票 / 债券 / 基金、现货 / 期货 / 期权、发行 / 交易、结算 / 交割、监管 / 自律成对辨析。
- 套期保值先问现货风险方向，再看头寸；套保不等于无风险。
- 计算题写明单位、合约乘数、费用、基差与保证金假设。学习内容不扩展为投资建议。

## 10. 讲课风格与对话里的图

- 讲师口吻，先结论后展开；多用「看到 xx 就想到 xx」这类识别口诀，但要说清适用条件。
- 推断标「推断」并写依据；不使用机构的「高频」说法；参考答案注明是机构整理。
- 政治、时政、法律、证券期货制度：核官方原文和施行时间，历史口径与现行口径分开写；核不到就说待核。
- 终端不渲染 mermaid。对话里用 ASCII 框图或小表，例如本课在题型地图上的位置：

```text
方程与比例 ✓ ─ 排列组合 ▶ ─ 几何 ─ 其他 ─ 行程 ─ 最值 ─ 工程 ─ 经济 ─ 容斥（可选）
```

- 带图题用文字描述图形（形状、标注、已知长度和角度），题图请学习者看课程页；完整的题型地图和真题覆盖也在课程页考情课的两张表格里。
