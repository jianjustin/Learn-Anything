# 国考模板

一个考试模块一门课。目标只有一个：学习者**一通百通**，懂这个模块有哪几类题、每类考什么、怎么认出来、怎么解，再用题检验。第 1 课拆解考情和题型地图；中间每类题型一课，先讲概念、识别线索和解法，再用一道**有出处的真题**示范，然后出 1–2 道原创变式，错了回到概念，不连刷；最后一课讲考场上的做与跳。

本文只写国考课和通用流程不同或多出来的地方，其余一律照 SKILL.md 和三份 references 走。下文标「覆盖」的条目与通用规则冲突，以本文为准。

## 题库在哪

**题库路径取 SKILL.md「路径约定」里的「国考题库」。** 它应当是一个绝对路径（guokao_sprint 仓库的根目录）。它是空的，或者仍是一段含 `user_config` 字样的占位符文本时，停下，告诉学习者用下面任一方式配置，然后结束本次调用；**不讲课，不凭记忆出真题**：

- 重新运行仓库里的安装脚本：`bash install.sh --guokao-repo <绝对路径>`；
- 或者运行 `/plugin configure learn-anything@learn-anything-local`，填写「国考题库仓库」。

下文的写法：

- `<国考题库>`：上面那个仓库根目录的实际路径；`<题库>` 指 `<国考题库>/guokao-sprint/references`。
- `<skill 目录>`、`<课程目录>`：SKILL.md 路径约定里的两个路径；`<课程文件>` 指 `<课程目录>/<dir>/course-data.js`，`<dir>` 取列课程命令输出里这门课的 `dir`。

题库只有一份，留在仓库原处，下表里的 `<题库>/...` 都直接读，不复制进课程目录或 skill 目录。真题库 `<题库>/zhenti/<slug>.md` 每题一个条目 `### {行标签}-{题号}`；`<slug>.data.js` 由它生成，`zhenti/img/` 是题图。

**判断一道题能不能用，看题库，不看课程里的表格或 `templateData` 的快照**：先看 `<slug>.data.js` 里这道题有没有 `hold` 标记（有就停，不再读它的任何内容），再用下面的办法只读 md 条目的字段行（`- 用途：`、`- 一致：`）。题库只在学习者要求追加题目时按 `import-questions.md` 修改。

### 读题库 md 的规矩（硬规则）

`<题库>/zhenti/<slug>.md` 有 100–400 KB，里面有 `hold` 题（学习者 11-21 要做的整卷）的题干、答案和解法，整个读进来就泄露了。所以：

- **永远不整个读 `<slug>.md`**（不用 Read 读全文，不用 `cat`、不用 grep 把条目正文大段打出来）。
- **不读 `hold` 条目**：要读任何一个条目之前，先在 `<slug>.data.js` 里确认这道题没有 `hold: true`。
- **「本课有哪些题」看 `<slug>.data.js`**：`items` 里的 `year`、`no`、`type`（以及 `type2`、`hold`、`drill` 标记）只有年份、题号、题型、用途标记，没有题干。按 `type` 筛出对应本课题型节点的题；也可以看课程里「真题覆盖」表（那是它的副本）。申论、计算机、证券期货的「按课汇总」在 md 开头，随开头一起读（见下表）。
- **读单个条目的办法**：先用 `grep -n '^### <行标签>-<题号>$' <题库>/zhenti/<slug>.md` 找到条目所在行 N，再用 Read 读，`offset` 取 N，`limit` 只到下一个 `### ` 行之前（用 `grep -n '^### '` 的输出得到下一条的行号，条目通常不超过 50 行；最后一个条目后面没有 `### ` 行，`limit` 取 50）。
- **只查 `用途`、`一致` 时**只读字段行，不看题干：`grep -n -A9 '^### <行标签>-<题号>$' <题库>/zhenti/<slug>.md`（`-A9` 只覆盖到 `- 题图：` 行，不会碰到 `#### 题干`）。
- 学习者明确说已做完某年整卷并要复盘时，才可以读那一年的 hold 条目，仍按上面的办法一条一条读。

## 三个脚本

国考课的题型地图和真题覆盖存在 `templateData.growth` 里（题库在这门课上的副本，加上「已示范」标记），页面上显示为考情课末尾的两张表格卡「题型地图」「真题覆盖」。这两张卡带 `generated` 标记，由脚本生成。**不手改这两张表格卡，也不手改 `templateData.growth`**，一律交给下面的脚本：

- **同步**：`node <skill 目录>/scripts/guokao.mjs sync "<国考题库>" "<课程文件>" [--demo <行标签-题号>]...`。从题库重算题型数、新增题型和真题清单，保留已有的「已示范」标记，重写两张表格卡。`--demo` 给一道题加「已示范」标记，可以写多个。什么时候跑：**续学开始时**跑一次；**示范完一道真题**后带 `--demo` 跑；**追加题目**之后跑。
- **题图**：`node <skill 目录>/scripts/guokao.mjs image "<国考题库>" "<课程文件>" <课程 id> <行标签-题号> --alt "<图形的文字描述>"`。把题库里这道题的题图内嵌成一张 `html` 卡，标题「<行标签>-<题号> 题图」，插在那一课**最后一张 `steps` 卡之后**；重复运行时原位替换。
- **建课**：`node <skill 目录>/scripts/guokao.mjs new "<国考题库>" "<课程目录>" <slug>`。按题库的默认大纲建一门国考课（全部 `todo`，带两张表格卡和系列「国考」），登记进总览页，成功时只输出课程页的绝对路径。

三个脚本都先在内存里算好并校验，通过才写，不必再跑校验命令。退出码 0 成功；1 出错，课程文件不动，把 ✗ 后面的信息原样告诉学习者，不要手改课程文件绕过去；2 参数不对。sync 输出 △ 行（丢掉了题库里已没有的题的标记、补进了新题型）时，转告学习者。`--demo` 和 `image` 遇到 hold 题会拒绝：本来就不该拿 hold 题去跑。

脚本会改写课程文件。跑之前先把自己要写的内容写完并校验；跑完之后，下一次手改之前重新读文件。

`templateData.growth` 只有一处可以手改：调整大纲删课或合并课时，把指向那一课的题型节点的 `lesson` 改指到别的课（见「调整大纲」），改完跑一次 sync 重写表格。

## 入口与开题（覆盖）

- **找课**：九门课都已在课程目录里（系列「国考」）。用 SKILL.md 的列课程命令找，输出里 `template` 为 `guokao` 的就是国考课；模块名到 slug 的对照见 `outline-patterns.md`「slug 规则」，对不上时列出候选问学习者。
- **点名一个模块**：这门课已经开讲就按「续学」走；全部课都是 `todo` 就按下面的「开题」走。不再另开一门同主题的新课；学习者明确要重开时，见下一条。
- **重开一门国考课**（覆盖通用的「重开」做法）：先照通用规则用 `AskUserQuestion` 确认，说明会清掉这门课的全部进度和练习记录。确认后不要删课程重建（`new` 遇到已存在的课程目录会拒绝），也不要手搭一份新的课程文件，只在现有课程文件上这样改（保留的部分原样不动）：
  1. 保留 `template`、`templateData`、`series`，以及考情课里两张带 `generated` 标记的表格卡；
  2. 每一课：`status` 设 `"todo"`，`mastered` 设 `false`，`cards` 设 `[]`（考情课的 `cards` 只留那两张表格卡）；
  3. `review` 设 `[]`；`resume` 指向第一课，`note` 写「尚未开始」；更新 `updatedAt`；
  4. 运行 SKILL.md 的校验命令，通过后跑 `guokao.mjs sync "<国考题库>" "<课程文件>"`，让表格卡和 `templateData.growth` 与题库一致；
  5. 然后按下面「开题」第 4 步重新开课。
- **只说「继续考公」「继续国考课程」，不带模块**：只列 `template` 为 `guokao`、已经开讲的课，每门一行（主题、已讲几课 / 共几课、已掌握几课、待回顾几条、断点说明），问继续哪门或开新模块。
- **课程不存在**（被删了，或以后加了新模块）：按 `<题库>/outlines.data.js` 在对话里给出默认大纲，确认后运行建课命令 `guokao.mjs new`，再按确认时的调整修改课程，然后按开题第 4 步开课。不手搭课程文件。
- **开题**：
  1. 不问两个开题问题。`mission`、`approach`、`researched`（`"skipped"`）、`resources`（空）、`series`、`template: "guokao"` 和 `templateData` 都已由脚本写好，不改写。
  2. 读 `outline-patterns.md`、课程文件里的大纲，和 `<题库>/zhenti/<slug>.md` 开头（从文件第一行读到第一个 `###` 之前，用 `limit` 截住，不往下读题目）。
  3. 按 `outline-patterns.md` 的格式在对话里给出大纲，用 `AskUserQuestion` 问确认还是调整。调整只改这一门课；可选课以课程文件里的 `optional` 为准，可以和学习者商量，不自行改动。
  4. 确认后：第一课设 `current`，`resume` 指向第一课，校验，打开课程页，开讲第 1 课。

## 真题用途规则（所有课通用）

真题库每题的 `- 用途：` 决定能怎么用：

| 用途 | 年份（数量关系；其余行测五模块） | 课上能怎么用 |
|---|---|---|
| `hold` 留作整卷 | 2025、2026；2025、2026 | 学习者计划 11-14 做 2025 整卷、11-21 做 2026 整卷，当未见卷检验。课上**只能出现题号和题型**（「2025 年第 71 题是工程题」）；题干、选项、答案、解法、题图不进对话，也不进课程文件；不作变式蓝本。学习者明确说已做完该年整卷并要复盘时才可以讲 |
| `demo` 可示范 | 2023、2024；2024 | 真题示范和变式蓝本**只从这里选**。示范后跑 `guokao.mjs sync ... --demo <行标签-题号>` |
| `drill` 组练 | 2022；无 | 留给策略课的限时组练；此前各课不示范、不当蓝本、不提前讲 |

- **追加来源**：行测的 2021 副省级、2024 地市级为 `demo`；2025、2026 地市级与同年副省级共用材料的题为 `hold`（同年副省级相同的题未收），其余 `demo`。行标签 `时政模拟2026XX` 是**机构时政模拟题、不是真题**，用途 `drill`，只作政治理论、常识课的课后组练或策略课组练，示范时不用，提到时要说明是模拟题。
- **计算机、证券期货（证监会 2021–2025）与申论（2024–2026 副省级、地市级）**：学习者确认全部 `demo`，都可以示范和作变式蓝本（存疑、待核题除外）。证监会卷的法规题按出题当年口径判对错，条目备注写了「现行规定待核」的，示范时要说明口径可能已变。申论示范先从 `<题库>/zhenti/shenlun-cailiao/<行标签>.md` 读给定资料，再讲题。
- 条目里 `- 一致：存疑` 或 `- 一致：待核` 的题**不作示范、不作变式蓝本、不进组练**。
- 示范题必须标出处：年份、卷别、题号、参考答案出处（条目 `- 参考答案：` 里的文件与页码），并说明参考答案为机构整理、非官方。不确定的年份、题号、页码不写，回真题库核。
- 带图题：对话里用文字描述图形（取条目题干里的【图】转写），页面上用 `guokao.mjs image` 放题图。
- **没有真题库的模块**：不编真题、不编题量。示范用自编例题并标「原创例题，非真题」，告诉学习者可以按 `import-questions.md` 导入真题。

## 讲课

一门课有三种课，讲法见 `lesson-guide.md`：

- **考情课**（第 1 课，id `kaoqing`）：考几题、题号段、参考时限、分几类、每类近三年各考几题、2027 侧重推断。不发题，掌握规则见下文「三处覆盖」。
- **题型课和方法课**（中间各课）：每课七步——开课改页面 → 是什么、考什么 → 识别线索 → 解法与适用条件 → 真题示范 → 原创变式 → 课末。
- **策略课**（最后一课，id `celve`）：行测「做与跳：限时策略」、申论「考场作答策略」、计算机与证券期货「串讲与多选辨析策略」，课末一次限时组练或限时小题。

### 变式就是本课的检验

课中出的每一道原创变式都是一次检验，记进本课的 `practice` 卡，参与「已掌握」和待回顾。不另外出检验题。

- **发题**：往本课 `practice` 卡追加一条，`q` 写题目全文（含选项），不写 `answer`，运行校验，再在对话里发题，**发题即停**。选择题是客观题，不写 `rubric`；申论小题写 `rubric`（见下）。
- **评分**：选择题当场判。补全 `yours`、`ok`、`answer`，答错时写 `why`，按通用规则处理 `mastered` 和 `review`。
- **跳过**：照通用规则记 `skipped: true`。
- **出几道**：第一道答对，再出一道换角度的变式；答错，讲清错因后最多再给一道；每课最多 2 道。

### 练习记录的四条约定（覆盖）

`practice` 条目只用通用字段，国考多出来的信息按下面的位置写：

- **出题依据**：接在 `q` 末尾另起一行，`出题依据：仿 2024-63（换了倍数作用的对象）`。只能仿 `demo` 题。
- **错因**：写在 `why` 开头，`错因：<中文>。<错在哪一步、回链到哪一点>`。中文只取七个之一：概念不清、审题、方法、计算、条件用错、时间、不明。只记一个主因，次要原因写在后面。
- **用时**：学习者报告了用时，接在 `yours` 末尾另起一行，`（用时 N 分钟）`；`yours` 前面的部分仍是原话，一字不改。
- **跳过**：组练里跳过的题记 `skipped: true`，不写 `yours` 和 `ok`，跳题依据写进 `why`：`跳题依据：<为什么跳>`。

### 掌握与待回顾的三处覆盖

其余照通用规则：每评完一条按这一条改 `mastered`，没过关的写进 `review`。

- **考情课**：不发题（覆盖「每课至少检验一次」）；课末设 `done` 时同时设 `mastered: true`。
- **策略课组练**：整次组练算**一次**检验。开练前请学习者自己定过关门槛（正确率和用时，如「15 题对 11 题、10 分钟内」），写进组练汇总条目的 `rubric`。报告后按门槛判汇总条目的 `ok`，本课 `mastered` 跟着这一条走：过关设 `true`，没过关设 `false`。各题条目照常记 `yours`、`ok`、`answer`，但不单独改 `mastered`。有错题或没过关时，只往 `review` 加**一条**，列出错题题号和错因，超时就写超了多少，不逐题加：过关但有错题，写 `{ "lesson": null, "text": "组练错题：……" }`，`mastered` 设 `true`（待回顾不能指向已掌握的课）；没过关，`lesson` 写策略课 id，`mastered` 设 `false`。写法见 `lesson-guide.md`「策略课」。
- **申论小题**：要判 `ok`，由讲课的你对照给定资料和参考要点来判，**不交给 `answer-grader`**（评分子代理看不到给定资料）。`rubric` 写成要点清单并写明门槛，发题时就写好。

### 示范和题图怎么落到页面

示范讲完一道真题，依次：

1. 把这道题的推理写成本课的一张 `steps` 卡，标题「真题示范：<年份> <卷别> 第 N 题」，放在本课已有的 `practice` 卡之前，运行校验。出处写在卡里，不写 `refs`（国考课没有资料清单）。
2. 带图题：运行 `guokao.mjs image`，题图插在这张 `steps` 卡后面。
3. 运行 `guokao.mjs sync "<国考题库>" "<课程文件>" --demo <行标签-题号>`，「真题覆盖」表里这道题标上 ★。
4. 下一次手改前重新读课程文件。

### 课末的卡片（覆盖默认的卡片约定）

- **题型课和方法课**按这个顺序：`points`「要点」→ `points`「识别线索」→ `points`「解法」→ `steps`「真题示范」（示范时已写）→ 题图（带图题，脚本已插）→ `practice`（发题时已写，课末只检查每条都有 `yours` 或 `skipped`，评过的都有 `answer`）→ `quote`。课末补写的卡放在对应位置，不动已有的卡。按需加 `table`、`compare`、`questions`。
- **考情课**：`points`「要点」→ `note`「2027 推断」（每条标「推断」并写依据，不说「高频」）→ `quote`，放在两张表格卡之前。近三年分布看「题型地图」表，不另写分布表。
- **策略课**：`points`（时间预算与顺序）→ `steps`（跳题线索清单）→ `practice`（组练）→ `quote`。这是最后一课：设 `done` 后没有下一课，`resume` 留在本课，`note` 写「全部课程已讲完」。

## 续学（补充）

- 读完课程文件、给出回顾之后，先跑一次 `guokao.mjs sync "<国考题库>" "<课程文件>"`，题库新增的题和题型落到表格上；然后重新读课程文件。
- 发出后还没作答的组练题，条目里只有题号和题型时，按「读题库 md 的规矩」从 `<题库>/zhenti/<slug>.md` 按题号读出题干重发（组练题是 `drill`，不是 `hold`）。
- 回顾时提一句上一课答错的变式的错因，帮助衔接。

## 调整大纲（补充）

- 只改这一门课，照通用的「调整大纲」做。
- 删除或合并一课之前，先把 `templateData.growth` 里指向它的题型节点的 `lesson` 改指到别的课：题型节点被真题清单引用，不能随课一起删。然后跑一次 sync，「题型地图」表的「对应的课」随之更新。
- 新增一课只是为了放新题型时，见 `import-questions.md` 第 3 步。

## 常见错误

| 错误 | 正确做法 |
|---|---|
| 「国考题库」没配置，凭记忆讲真题 | 停下，告诉学习者怎么配置 `guokao_repo` |
| 课上讲了 2025、2026 的题干 | `hold` 题只说题号和题型；学习者明确说做完那年整卷要复盘才可以讲 |
| 用 2022 组练题、时政模拟题或存疑题做示范，或看课程里的表格判断能不能用 | 看题库（`data.js` 的标记、md 条目的字段行），不看课程里的快照；示范和变式蓝本只用 `demo` 且非存疑、非待核的题 |
| 整个读 `<slug>.md` 找题，或读了 `hold` 条目 | 永远不整个读；`data.js` 找题，`grep -n '^### <行标签>-<题号>$'` 定位后按行号读单个条目，先确认没有 `hold` |
| 手改「题型地图」「真题覆盖」表或 `templateData.growth` | 跑 `guokao.mjs sync`；示范后带 `--demo` |
| 手写 base64 题图，或给 hold 题放题图 | 用 `guokao.mjs image`；hold 题不放 |
| 跑完脚本凭记忆接着改课程文件 | 跑完脚本先重新读，再改 |
| 变式只换数字 | 换条件或情境，标「原创变式」和出题依据，出题前自己独立解 |
| 答错后连发同类题 | 定位到步骤、回链概念，讲清后最多再给一道 |
| 组练每错一题加一条待回顾，或每题单独改 `mastered`；过关了待回顾却指向策略课 | 整次组练一次检验，按学习者定的门槛判汇总条目；只加一条待回顾：过关写 `"lesson": null`，没过关写策略课 id |
| 申论小题交给 `answer-grader`，或不判 `ok` | 你对照给定资料和要点清单判 `ok` |
| 课程不存在就手搭课程文件 | 跑 `guokao.mjs new` |
